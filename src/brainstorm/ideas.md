# Idea catalogue

Twenty-five ideas, grouped by where the thread is anchored. Each has an ID for the [comparison](comparison.md) and a card with the same fields: what it is, which [job](requirements.md#three-jobs) it does, what it protects against, its weak spot, and whether it could be built today.

All of these are brainstorm, not established practice, unless the card says otherwise. Add new ones with the [template](../appendix/idea-template.md).

## Anchored in hardware

| ID | Idea | One line |
|---|---|---|
| H1 | [The Arch](ideas-hardware.md#h1-the-arch) | One physical control no app can capture, which always starts the way back |
| H2 | [Real light](ideas-hardware.md#h2-real-light) | An exit that ends in real photons: a shutter or visor that opens onto the room |
| H3 | [The tether](ideas-hardware.md#h3-the-tether) | A literal cord or a home-pointing wristband, tied to the start spot |
| H4 | [Reality heartbeat](ideas-hardware.md#h4-reality-heartbeat) | A wrist device taps a private rhythm the content cannot know or copy |
| H5 | [Depth gauge](ideas-hardware.md#h5-depth-gauge) | A non-visual counter of how many layers deep you are |
| H6 | [Dead man's switch](ideas-hardware.md#h6-dead-mans-switch) | If you stop answering a gentle check, the world fades out |
| H7 | [Black box](ideas-hardware.md#h7-black-box) | An independent recorder of where you went, and when |
